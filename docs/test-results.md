# Отчёт о тестировании Support Service

## 1. Сводка

По ранее выполненным локальным проверкам команды `./gradlew spotlessCheck` и `./gradlew clean test` завершались `BUILD SUCCESSFUL`. Ранее зафиксировано 22 автоматизированных теста, однако распределение по уровням и фактические имена тестовых методов здесь ещё не сверены.

По скриншоту GitHub Actions подтверждён успешный workflow **Add automated deployment pipeline #8**: задачи `Build and Test`, `Publish Docker image`, `Deploy and Verify` завершены успешно (коммит `b4e1c49`, дата запуска уточняется по GitHub).

**Достоверный результат:** автоматизированная проверка развёртывания на временном GitHub-hosted runner прошла. **Не подтверждено этим запуском:** постоянное размещение на сервере или откат ранее работающей версии.

## 3. Результаты обязательных проверок

Заполнить после сопоставления методов из `src/test` с пунктами тест-плана:

| Показатель | Требуется | Фактически подтверждено |
|---|---:|---|
| Модульные тесты | ≥ 10 | Не пересчитано по методам |
| Интеграционные тесты | ≥ 6 | Не пересчитано по методам |
| Сквозные сценарии | ≥ 2 | Не сверено по методам |
| Тесты Kotlin | ≥ 3 | Не пересчитано по методам |
| Регрессионный тест | ≥ 1 | Ещё требуется доказательство исправленного дефекта |
| Нестабильность по времени/порядку | Не допускается | Требуется сверить использование Clock и зависимостей тестов |

## 4. Известные ограничения проверки

- GitHub-hosted runner — временная среда: после завершения задания контейнеры уничтожаются. Это не постоянный учебный стенд.
- Скриншот успешного workflow не подтверждает все граничные случаи бизнес-логики; их необходимо сопоставить с кодом тестов.
- Откат предыдущей версии образа отдельно не продемонстрирован.
