## Приёмка работ

- Рабочий REST API, PostgreSQL, Kotlin-статистика и воспроизводимый запуск.
- Автотесты Java/Kotlin, интеграционные тесты с PostgreSQL и отчёт покрытия.
- Запуск опубликованного образа, проверка API и демонстрация отката на предыдущую версию.
- Документы, инструкции и ссылки на результаты CI/CD.
