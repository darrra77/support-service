# Журнал дефектов Support Service

## BUG-001 - Потеря срока выполнения при редактировании заявки

| Параметр | Значение |
|---|---|
| Идентификатор | BUG-001 |
| Компонент | `TicketService` |
| Метод API | `PATCH /api/tickets/{id}` |
| Приоритет | Medium |
| Статус | Исправлен |
| Регрессионное тестирование | Успешно |

### Описание дефекта

При частичном редактировании заявки ранее установленный срок выполнения сбрасывался в `null`, если поле `dueAt` отсутствовало в JSON-запросе.

### Шаги воспроизведения

1. Создать заявку с приоритетом `HIGH` и установленным сроком выполнения.
2. Выполнить PATCH-запрос, передав новое описание и приоритет `MEDIUM`, но не передавая `dueAt`.
3. Получить заявку через `GET /api/tickets/{id}`.
4. Проверить сохранённое значение `dueAt`.

**Ожидаемый результат:** ранее установленный срок выполнения сохраняется.

**Фактический результат до исправления:** сервер возвращал HTTP 200, но значение `dueAt` становилось `null`.

### Причина возникновения

Метод `TicketService.updateTicket()` безусловно присваивал значение `request.getDueAt()`.

Если поле `dueAt` отсутствовало в JSON-запросе, его значение в DTO было равно `null`.

В результате ранее установленный срок выполнения удалялся.

### Реализованное исправление

В классе `UpdateTicketRequest` добавлены признаки присутствия необязательных полей:

- `descriptionProvided`;
- `dueAtProvided`.

Метод `TicketService.updateTicket()` изменён таким образом, чтобы необязательные поля обновлялись только при их наличии в запросе.

При этом сохранена возможность явно удалить срок выполнения, передав `"dueAt": null`.

### Регрессионное тестирование

| Тест | Тип | Результат |
|---|---|---|
| `testUpdatePreservesDueAtWhenOmitted` | Модульный | Успешно |
| `testPatchPreservesDueAtWhenOmitted` | Интеграционный | Успешно |

До исправления модульный регрессионный тест воспроизводил дефект и завершался ошибкой `AssertionFailedError`.

После исправления оба регрессионных теста завершились успешно.

Повторное выполнение полного набора из 27 автоматизированных тестов также завершилось без ошибок.

### Итог

**Дефект BUG-001 устранён.** Корректность исправления подтверждена модульным и интеграционным тестированием.
